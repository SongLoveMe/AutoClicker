# 🎯 通用连点器 (AutoClicker)

一个基于 Qt 6 开发的 Windows 自动点击工具。AutoClicker v2.4 以“工作流”为核心：一个工作流可以包含多个序列，每个序列保存自己的点击点、循环轮数和跳转条件；序列完整执行一轮后，根据条件决定是否进入后续序列。

## ✨ 功能特性

### v2.4 条件驱动工作流

| 能力 | 说明 | 状态 |
|------|------|------|
| 📋 **多序列工作流** | 一个工作流包含多个命名序列；默认依次命名为“序列 1”“序列 2”等 | ✅ 已实现 |
| 🔗 **顺序单链跳转** | 每个序列最多一条跳转规则，只能跳转到后续序列 | ✅ 已实现 |
| 🔴 **录制与手动添加** | 录制点击或延时读取当前鼠标位置，并自动尝试绑定该点所在窗口 | ✅ 已实现 |
| 🪟 **点位窗口绑定** | 点位保存窗口标题、进程名和类名，运行时重新定位窗口 | ✅ 已实现 |
| 🖼 **图片出现条件** | 绑定窗口画面出现模板时跳转；可导入模板或从截图取得模板 | ⚠️ 基础功能已实现，效果待优化 |
| 🎨 **颜色占比条件** | 在多边形区域中统计目标颜色占比，满足阈值时跳转 | ⚠️ 基础功能已实现，效果待优化 |
| 🔁 **循环结束跳转** | 当前序列完成设定轮数后，自动进入后续序列 | ✅ 已实现 |
| 💾 **工作流文件** | 保存为 `.acworkflow`，模板以 Base64 PNG 内嵌 | ✅ 已实现 |
| 📥 **导入与导出** | 导入同名工作流自动改名；可导出独立工作流文件 | ⚠️ 已实现，待人工验证 |

### 点击配置

| 参数 | 说明 |
|------|------|
| **鼠标按钮** | 左键、右键、中键；每个点位可独立设置 |
| **单点点击次数** | 每个点位可设置一次执行中重复点击的次数 |
| **重复点击间隔** | 同一点击点连续点击之间的间隔 |
| **下一点间隔** | 当前点位执行结束后，到下一点开始前的等待时间；录制时会记录相邻点击的间隔 |
| **序列循环轮数** | 每个序列独立设置；轮数完成后才评估该序列的跳转条件 |
| **点击方式** | 工作流级“模拟鼠标”或“无干扰点击” |

### 点击方式

| 方式 | 说明 | 当前建议 |
|------|------|------|
| 🖱 **模拟鼠标** | 通过 `SendInput` 发送鼠标输入，目标窗口需要可见、未最小化并处于前台 | 需要网页、浏览器或视觉条件时使用 |
| 🪄 **无干扰点击** | 向目标窗口发送鼠标消息，不移动或占用用户鼠标 | 不影响其他鼠标操作；目前仅在目标窗口前台时可靠，后台和最小化窗口尚未解决 |

无干扰点击不支持图片和颜色等视觉条件。不要将无干扰点击用于必须在后台或最小化窗口可靠完成点击的场景。

### v2.4 编辑与控制功能

| 功能 | 说明 |
|------|------|
| 🧾 **点位表格编辑** | 直接编辑全局坐标、相对坐标、按钮、点击次数、重复间隔、下一点间隔与绑定窗口 |
| ↕ **点位排序与批量操作** | 表格右键可添加当前位置、编辑、删除、删除所有点、上移、下移，空白处可解除当前序列全部窗口绑定 |
| 🎯 **条件配置** | 图片、颜色和循环结束三种条件按类型渐进式显示对应配置 |
| 🖼 **模板预览** | 已导入或截取的模板支持缩略图预览与独立窗口查看 |
| ▶ **运行状态控制** | 开始、暂停/继续、停止遵循统一引擎状态；工作流完成时弹出提示 |
| ⌨ **全局热键** | F6 开始/停止、F7 暂停/继续、F8 开始/停止录制 |

### 热键控制

| 热键 | 功能 |
|------|------|
| **F6** | 开始/停止工作流 |
| **F7** | 暂停/继续工作流 |
| **F8** | 空闲时开始/停止录制 |

F6/F7/F8 使用 Windows 全局低级键盘钩子捕获，不依赖 AutoClicker 是否处于前台。UAC、锁屏等安全桌面、内核级输入驱动和管理员权限隔离场景不属于用户态程序可以保证的范围。

## 📖 使用指南

### 界面说明

```
┌─────────────────────────────────────────────────────────────────────┐
│ 工具栏：打开 保存 导入 导出 起始序列 [开始] [暂停/继续] [停止]       │
├──────────────────┬────────────────────────────┬─────────────────────┤
│ 工作流与序列     │ 当前序列点位               │ 窗口与跳转条件      │
│                  │                            │                     │
│ 工作流树         │ 循环轮数                   │ 自动绑定窗口状态    │
│  ├─ 序列 1       │ [开始录制/停止录制]        │ 点击方式            │
│  └─ 序列 2       │                            │ 跳转条件摘要        │
│                  │ 点位表格：                 │ 运行状态            │
│ 右键：新建、     │ 全局/相对坐标、窗口、      │ [配置条件]          │
│ 重命名、排序、   │ 按钮、次数、两个间隔       │                     │
│ 删除             │ 右键：添加、编辑、排序、   │                     │
│                  │ 删除、解除序列窗口绑定     │                     │
├──────────────────┴────────────────────────────┴─────────────────────┤
│ 状态栏：当前状态、错误或结束原因、热键提示                          │
└─────────────────────────────────────────────────────────────────────┘
```

左栏、中栏和右栏均可拖拽调整宽度。常用的序列与点位操作放在右键菜单中，以保持主界面紧凑。

### 基础使用步骤

#### 1. 创建工作流和序列

1. 点击“新建工作流”。
2. 左栏会创建“序列 1”；在左栏右键可添加、重命名、上移、下移或删除序列。
3. 顶部“起始序列”决定每次运行的入口，它独立于当前正在编辑的序列。

#### 2. 添加点击点

1. 选中需要编辑的序列。
2. 点击“开始录制”或按 **F8**，在目标位置点击；再次点击按钮或按 F8 停止录制。
3. 也可在点位表格右键菜单选择“添加当前鼠标位置”，倒计时结束后自动保存鼠标位置。
4. 每次录制或手动添加都会尝试绑定鼠标所在窗口；双击表格单元格可以修改点位数据。

#### 3. 配置点击方式与循环

1. 设置当前序列的循环轮数。
2. 在右栏选择点击方式：一般网页、浏览器和视觉条件使用“模拟鼠标”。
3. 选择“无干扰点击”时，目标窗口必须保持前台；它不会移动用户鼠标，但不能可靠用于后台或最小化窗口。

#### 4. 配置序列跳转

1. 在右栏点击“配置条件”。
2. 选择“图片出现”“颜色占比”或“循环结束”。
3. 选择目标序列。目标必须位于当前序列之后。
4. 图片和颜色条件会在当前序列完整执行一轮后检测；循环结束条件会在达到循环轮数后跳转。
5. 保存条件并运行前，确认图片/颜色条件的目标窗口能够前台显示并正常截图。

#### 5. 运行与保存

1. 顶部选择起始序列。
2. 点击“保存”，将工作流保存为 `.acworkflow` 文件。
3. 点击“开始”或按 **F6**；按 **F7** 暂停或继续，按 **F6** 或“停止”结束。
4. 工作流全部完成时，程序会弹出完成提示；窗口无法定位或视觉条件无法截图时会停止并显示原因。

## 🆕 v2.4 功能详细说明

### 📋 条件驱动工作流

工作流是 v2.4 的基本运行单位。工作流包含一个或多个序列，每个序列依次执行自己的点击点并完成配置的循环轮数。点击引擎只会在一轮内的最后一个点及其间隔都完成后，检查该序列的跳转条件。

当前模型是单链顺序流程，例如：

```text
序列 1 ──图片出现──> 序列 2 ──循环结束──> 序列 3 ──完成
```

不支持跳回前面的序列、自循环、并行分支、多条件与/或组合或规则优先级。

### 🔴 录制模式

录制模式使用 Windows 低级鼠标钩子捕获左键、右键和中键点击。

1. 选择序列后，点击“开始录制”或按 F8。
2. 在屏幕上按实际顺序点击目标位置。
3. 程序记录按钮、全局坐标、相邻点击间隔，并尝试保存该位置所属窗口的标识和相对坐标。
4. 点击“停止录制”或再次按 F8 完成录制。

录制期间应避免点击 AutoClicker 自身界面，以免将不需要的点位写入序列。

### 🎯 窗口绑定与坐标

每个点位可以绑定其录制或添加时所在的窗口。绑定信息包括窗口标题、进程名和窗口类名；运行时会重新查找窗口，而不是持久化临时 HWND。桌面和任务栏等系统窗口也可作为绑定目标。

点位同时保存两类坐标：

- **全局坐标**：相对于整个虚拟桌面的屏幕坐标。未绑定点直接使用它；重新绑定时也以它作为锚点。
- **相对坐标**：相对于绑定窗口左上角的参考坐标，并保存绑定时窗口尺寸。窗口移动或缩放后，程序按当前窗口几何换算实际点击位置。

不同软件的缩放逻辑并不统一。自定义渲染界面、浏览器页面缩放、高 DPI 处理和游戏 UI 缩放都可能使窗口尺寸比例与控件逻辑位置不完全一致。因此，窗口绑定与相对坐标不能保证在所有应用缩放后仍准确命中同一控件；请在目标窗口实际大小下重新检查点位。当前版本维持现有换算逻辑。

### 🖼 图片出现条件

图片条件用于“只要绑定窗口中出现某个模板，就跳转”。模板可从 PNG/JPG 文件导入，也可从目标窗口截图中框选取得；已保存模板可预览。

图片匹配在绑定窗口的整个截图中执行，不需要多边形区域。此功能当前提供基础能力，但不同分辨率、DPI、缩放、画面变化和模板质量都会影响结果，尚不能保证识别稳定性。

### 🎨 颜色占比条件

颜色条件在目标窗口截图中框选一个任意多边形区域，设置目标颜色、容差、阈值和比较方向，再计算该区域内满足条件的像素占比。它适合进度条、血条或明确的状态色区域。

多边形必须闭合才可以保存。颜色取样与模板匹配一样受缩放、截图质量、抗锯齿、颜色渐变和界面主题影响，当前识别效果仍有待后续完善。

### 🔁 循环结束自动跳转

循环结束条件不依赖截图。当序列达到设置的循环轮数后，点击引擎直接切换到指定的后续序列。它适用于固定阶段流程，例如“序列 1 完成 10 轮后进入序列 2”。

### 🪄 无干扰点击

无干扰点击通过窗口消息发送点击，不会移动或占用用户正在使用的鼠标，因此不会影响用户其他点击。

当前已知限制：它只能在目标窗口处于前台时可靠工作，目标窗口被遮挡、置于后台或最小化后均不能保证完成点击。它也不支持图片和颜色视觉条件。需要稳定执行网页、浏览器或视觉条件的场景，请使用“模拟鼠标”并保持目标窗口前台、可见、未最小化。

### 💾 工作流存储与导入导出

工作流使用版本化 JSON 格式的 `.acworkflow` 文件存储，模板 PNG 以 Base64 数据内嵌，因此文件可以独立复制和分享。默认保存目录为程序目录下的 `workflows/`；无写入权限时，程序会要求选择可写位置。

支持保存、打开、导入、导出和删除。旧单序列配置可迁移成无跳转规则的单序列工作流。导入和导出逻辑已经实现，但截至 2026-08-15 尚未完成完整人工验证。进行导入/导出测试时，请使用副本，不要把唯一的工作流文件作为测试源。

## 🔧 构建指南

### 环境要求

运行已发布安装包：Windows 10/11 64 位。

从源码构建：Windows 开发环境，使用 Qt 6.5.3 + Qt MinGW 13.1.0 + Ninja。

| 组件 | 版本 | 说明 |
|------|------|------|
| Qt | 6.5.3 | GUI 框架 |
| CMake | Qt 附带版本 | 构建配置工具 |
| MinGW | 13.1.0 | C++17 编译器；必须使用 Qt MinGW |
| Ninja | Qt 附带版本 | 构建工具 |
| Inno Setup | 6 | 发布安装包 |

### 开发环境配置

本项目默认使用以下工具路径：

```text
Qt 6.5.3:     D:\Qt\6.5.3\mingw_64
MinGW:        D:\Qt\Tools\mingw1310_64
CMake:        D:\Qt\Tools\CMake_64
Ninja:        D:\Qt\Tools\Ninja
```

不要使用 MSYS2 的 MinGW 编译本项目，否则会与 Qt 运行库不兼容。

### 构建步骤

```powershell
# 1. 设置环境变量
$env:PATH = "D:\Qt\Tools\mingw1310_64\bin;D:\Qt\6.5.3\mingw_64\bin;D:\Qt\Tools\CMake_64\bin;D:\Qt\Tools\Ninja;$env:PATH"

# 2. 配置 Debug 构建
cmake -G Ninja `
    -DCMAKE_BUILD_TYPE=Debug `
    -DCMAKE_PREFIX_PATH=D:/Qt/6.5.3/mingw_64 `
    -DCMAKE_C_COMPILER=D:/Qt/Tools/mingw1310_64/bin/gcc.exe `
    -DCMAKE_CXX_COMPILER=D:/Qt/Tools/mingw1310_64/bin/g++.exe `
    -B build

# 3. 构建并执行测试
cmake --build build
ctest --test-dir build --output-on-failure

# 4. 运行
build\AutoClicker.exe
```

### 发布安装包

普通用户运行发布安装包时无需安装 Qt、MinGW、CMake 或 Ninja。安装器支持选择安装目录、当前用户或所有用户安装、可选桌面快捷方式和卸载入口。

#### 一次性准备

1. 安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)。默认路径为 `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`。
2. 确认 Qt 6.5.3、Qt MinGW 13.1.0、CMake 和 Ninja 位于本 README 所列路径。

#### 每次发布

1. 更新 `CMakeLists.txt` 的 `project(AutoClicker VERSION x.y.z ...)`，这是程序、安装包和发布文件名的唯一版本来源。
2. 同步更新 README 的版本徽章、功能说明、已知限制和更新日志。
3. 在 PowerShell 中运行：

```powershell
.\scripts\package.ps1
```

如 Inno Setup 安装在其他位置，可指定路径：

```powershell
.\scripts\package.ps1 -InnoSetupPath "D:\Tools\Inno Setup 6\ISCC.exe"
```

脚本使用 `build-release/`、`dist/` 和 `release/` 作为本地产物目录，生成安装包和 SHA-256 校验文件。这些产物不提交到 Git。
